# Prompt 2: Install the PPT Visual Skill

> **Instructor note:** Walk students through finding and installing the ppt-visual skill into Codex.

## Where to Find Skills

Browse the skill directory at: https://github.com/claude-office-skills/skills

This is where you can discover skills for Codex or Cowork. There are hundreds of skills available for presentations, spreadsheets, documents, and more. Today we are installing the ppt-visual skill, which teaches Codex how to design professional presentations with proper layout, visual hierarchy, color palettes, and typography.

## How to Install

### Step 1: Download the Skill File

1. Go to the GitHub repo: https://github.com/claude-office-skills/skills
2. Navigate to the `ppt-visual` folder
3. Open the `SKILL.md` file
4. Click the "Raw" button (top right of the file)
5. Right-click and "Save As" to download the file as `SKILL.md` to your computer

File link: https://github.com/claude-office-skills/skills/blob/main/ppt-visual/SKILL.md

### Step 2: Upload into Codex

1. Open Codex
2. Use Skill Installer Skill
3. Upload the `SKILL.md` file you just downloaded
4. Confirm the skill appears in your active skills list

### Step 3: Verify

Once the skill is active, you should see "ppt-visual" listed under your installed skills. Codex now knows how to design professional presentations with proper layouts, visual hierarchy, and design principles.
