# Practice Solutions: Tidewater Launch Kit

Open this folder as its own Codex project. It includes the Tidewater brand bible, a local release CSV, and three prompts.

## What's here

- `brand/tidewater_brand_bible.md`
- `datasets/tidewater_spring_release.csv`
- `prompt_1_setup_and_heroes.md`
- `prompt_2_canva_carousels.md`
- `prompt_3_launch_email_plan.md`

## Student flow

1. Launch Codex from this folder.
2. Paste prompt 1.
3. Paste prompt 2.
4. Paste prompt 3.

This practice uses Canva and local files only. It does not use Google Drive, Google Calendar, or Gmail.
