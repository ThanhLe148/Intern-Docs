# Gogi Republic Brand Assets

These six images are pre-generated for the practice opportunity. Students should use them as visual anchors for the Gogi Republic skill, promotional flyer, and landing page. Do not regenerate them during this practice.

## What's here

- `hero_grill_table.png`, Korean BBQ table grill mid-service
- `texture_grill_flame.png`, close-up grill grate with flame and smoke
- `texture_banchan.png`, banchan bowls on a dark table
- `texture_neon_table.png`, red neon reflection on the tabletop
- `mj_portrait.png`, founder portrait for MJ Park
- `logo_concept.png`, Gogi Republic wordmark concept

## How the prompts use them

- Prompt 1 references the assets so the skill can describe when to use each image
- Prompt 2 uses the logo, hero table, and texture images for a promotional flyer
- Prompt 3 uses the hero, textures, MJ portrait, and logo for the landing page

The goal is not image generation. The goal is to teach students how a brand skill can carry voice and visual direction into real outputs.
