# Practice Solutions: Gogi Republic

Open this folder as its own Codex project. It includes the Gogi Republic brand bible, six pre-generated images, and three prompts.

## What's here

- `brand/gogi_republic_brand_bible.md`, the brand bible students use to build the skill
- `assets/`, the image pack for the restaurant skill, flyer, and landing page
- `prompt_1_create_brand_skill.md`, builds `AGENTS.md` and `.agents/skills/gogi-republic/SKILL.md`
- `prompt_2_promotional_flyer.md`, creates a promotional flyer for the Koreatown opening
- `prompt_3_landing_page.md`, creates the Gogi Republic landing page

## Student flow

1. Launch Codex from this folder.
2. Paste prompt 1.
3. Restart Codex so the new skill is discovered.
4. Paste prompt 2.
5. Paste prompt 3.

That is the whole practice. The point is to see how the same brand-skill workflow changes when the brand voice is louder, hungrier, and more restaurant-specific than Casa Verde.
