# Casa Verde Brand Assets (Pre-Generated)

These 6 images were generated by your instructor before class using Codex image generation. You don't generate new ones in this project. You build a brand skill that references these visuals.

If you joined the class without the assets, ask your instructor to share the pre-generated set, or run `_instructor_prep/prompt_0_generate_brand_assets.md` from the course materials.

## What's here
- `hero_living_room.png`, the Casa Verde Austin living room hero shot
- `texture_reclaimed_oak.png`, close-up of reclaimed oak grain
- `texture_limestone.png`, close-up of hand-finished limestone
- `texture_linen.png`, close-up of undyed linen weave
- `elena_portrait.png`, founder Elena Reyes
- `logo_concept.png`, Casa Verde wordmark

## How the prompts use them
- Prompt 1 references the assets folder so the skill can describe when to reach for which image
- Prompt 3 (Instagram) uses `hero_living_room.png` as the post image and writes a caption against what's actually visible in it
- Prompt 4 (landing page) drops the hero, the textures grid, the Elena portrait, and the logo into the right places on the page

## Why we pre-generate
The skill is more meaningful when it has real visuals to reference. Generating images live during class would eat 25 minutes from the 60 minute slot. Project 09 is where you do your own image generation work.
